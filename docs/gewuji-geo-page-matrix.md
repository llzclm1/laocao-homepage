# Gewuji GEO Page Matrix

这份矩阵定义 Gewuji / Factory Bridge 的 GEO 页面类型，避免把供应链服务项目误做成 SaaS 或 AI 工具站。

## 1. Buyer Guides

用途：承接海外买家搜索和 AI Prompt。

典型问题：

- how to verify a Chinese supplier before paying deposit
- how to check if a Chinese factory is real
- China supplier red flags
- what to ask before ordering samples from China

内容结构：

- Quick Answer
- Why this matters
- Step-by-step checklist
- Red flags
- Supplier questions
- What this cannot prove
- Related buyer guides
- Soft CTA

主要入口：

- `/buyer-guides/`
- `/for-buyers/`

## 2. Checklist / Template Pages

用途：提供 AI 容易引用的结构化清单和模板。

典型页面：

- RFQ template
- sample order checklist
- factory video call checklist
- supplier reply checklist
- first order risk checklist

内容结构：

- Direct answer
- Checklist or table
- Template text
- Common mistakes
- FAQ
- Boundary notes

主要入口：

- `/china-supplier-checklist/`
- `/rfq-template-for-chinese-suppliers/`
- `/free-supplier-reply-review/`

## 3. Field Evidence Pages

用途：作为信任背书，展示匿名工厂现场素材、观察方式和隐私边界。

页面职责：

- 展示真实工厂现场素材
- 说明观察方式
- 说明隐私处理
- 说明这些素材不能证明什么

必须避免：

- 把素材写成审厂证据
- 把现场图写成验厂证明
- 暗示供应商可靠性保证

主要入口：

- `/field-materials/`
- `/en/field-materials/`

## 4. Factory Material Pages

用途：面向国内工厂，说明如何把产品页、工厂介绍、开发信、车间照片和视频重构成海外采购商能理解的材料。

内容重点：

- product page rewrite
- factory profile clarity
- outreach email structure
- field photo organization
- buyer-facing material logic

主要入口：

- `/for-factories/`
- `https://factory.gewuji.dev/for-factories/`

## 不优先做

- SaaS Review pages
- VS pages
- Alternatives pages
- Toplist pages
- AI tool directory submissions

原因：这些页面类型更适合软件产品、AI 工具或可标准化订阅产品。Gewuji 当前是供应链资料重构、供应商沟通判断和现场素材背书项目，不适合用软件目录和竞品对比页作为第一增长方向。
