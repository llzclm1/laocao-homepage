# External GEO Distribution Playbook for Gewuji / Factory Bridge

This playbook defines how Gewuji / Factory Bridge rewrites website topics into useful, platform-native external content without spam, fake authority, or copied syndication.

## 1. Goal

External GEO Distribution is not about manufacturing low-quality backlinks. It is about rewriting core website topics into native content that fits each platform, so multiple trusted surfaces can build a topic evidence chain around Gewuji / Factory Bridge.

Core goals:

- Help overseas buyers understand Chinese suppliers before samples, deposits, tooling fees, and bulk orders.
- Help Chinese factories express products, factory capability, workshop photos, and outreach materials in buyer-friendly English.
- Build external topic signals around China supplier checks, factory reality, supplier communication, field materials, and buyer-facing factory content.
- Increase the chance that Google, ChatGPT, Perplexity, Gemini, and AI Overview understand and cite Gewuji content.

## 2. What This Is Not

This is not:

- mass posting
- spun content
- parasite SEO abuse
- Reddit spam
- link dropping
- copied-and-pasted blog syndication
- fake case studies
- fake audits
- fake supplier verification
- guaranteed supplier safety
- 100% safe sourcing claims
- formal factory audit
- legal due diligence
- quality inspection
- compliance certification

## 3. Suitable Platforms

### LinkedIn

Purpose:
Professional observation, sourcing communication insights, factory material clarity, buyer-side risk thinking.

Suitable content:

- short professional posts
- practical checklists
- founder/operator observations
- China supplier communication notes
- factory material rewrite examples without exposing private information

### Reddit

Purpose:
Natural participation in sourcing, ecommerce, import, small business, manufacturing, and Alibaba-related discussions.

Suitable content:

- direct replies
- practical comments
- no hard selling
- no repeated links
- no copy-paste
- no fake persona
- answer first, link rarely

### Medium / Substack

Purpose:
Long-form external essays and practical sourcing guides that expand on website topics.

Suitable content:

- rewritten long-form articles
- case-style breakdowns
- checklist-based guides
- non-promotional educational posts

### Quora

Purpose:
Direct answers to buyer questions.

Suitable content:

- answer the question directly
- include 4-6 practical checks
- mention boundaries
- optional link only when highly relevant

### X / Twitter

Purpose:
Short insights and distribution snippets.

Suitable content:

- one sharp observation
- 3-5 bullets
- link rarely
- use as discovery and testing channel

## 4. Relationship Between Website Content and External Content

The website is the source of truth. External platform content is the rewritten distribution layer.

Rules:

- External content should be based on website topics, but not copied word-for-word.
- Each external post should answer one clear question.
- The same idea can be adapted to multiple platforms with different structure and tone.
- Website article = complete reference.
- LinkedIn = professional insight.
- Reddit = natural reply.
- Medium/Substack = expanded essay.
- Quora = direct answer.
- X = short hook or checklist.

## 5. Link Rules

First 7-14 days:

- no links by default
- focus on account trust
- answer questions naturally
- collect questions and language patterns

After day 15:

- link only when highly relevant
- do not link in every post
- do not use the exact same link sentence repeatedly
- avoid link-first answers
- link should appear after value has already been given

Allowed light link sentences:

- "I wrote a more detailed checklist here if useful."
- "Here is a longer version of the checklist if you want to compare the details."
- "I keep a practical buyer checklist here, but the main points are above."

Forbidden:

- "Check out our service"
- "We guarantee supplier safety"
- "Use our audit"
- "Best supplier verification service"
- repeated homepage links
- unrelated links

## 6. Account Trust Rules

LinkedIn:

- use a consistent professional profile
- post practical sourcing observations
- comment on relevant industry posts
- avoid daily sales pitches

Reddit:

- participate before linking
- answer without links first
- avoid posting the same answer across subreddits
- never pretend to be a buyer if speaking as operator
- respect subreddit rules
- stop if replies are removed or downvoted as promotional

Quora:

- answer narrow questions
- avoid overlinking
- keep answers practical
- do not make exaggerated claims

Medium/Substack:

- publish slower, more polished posts
- include clear disclaimers
- link to related website guide only when natural

## 8. Weekly Workflow

Every week:

1. Pick 3 website topics.
2. Rewrite each into 2-4 external formats.
3. Publish selectively, not everywhere at once.
4. Reply to real questions first.
5. Record links, platform, topic, result.
6. Check whether the post survived, got engagement, or looked promotional.
7. Feed real questions back into `/buyer-guides/`.

- legal due diligence
- quality inspection
- compliance certification
- supplier reliability guarantee
- payment protection

Field Materials are not:

- inspection proof
