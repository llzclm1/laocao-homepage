# GSC 早期优化规则

这份文档用于约束早期 SEO 动作，避免因为数据少而做过度调整。

## 可执行规则

- `impressions > 0` 且 `averagePosition` 在 30-80：先补 title、H1、FAQ 和内部链接。
- `impressions > 0` 且 query 相关：保留页面，并做小幅内容优化。
- `impressions > 0` 但 query 不相关：先记录，不急着删除。
- CTR 低但排名低于 30：先不用管 CTR，重点是提升排名。
- 排名 8-30：优先强化内容深度、页面结构和内部链接。
- 排名进入前 20 后：再重点优化 title 和 description，提高 CTR。
- 页面有曝光但没有点击：不等于页面失败。
- query 奇怪：不等于页面必须 noindex。

## 禁止动作

- 不因为 0 点击删除页面。
- 不因为少量不相关 query 立刻 noindex。
- 不因为平均排名靠后就重定向。
- 不在没有页面级数据前大改 sitemap。
- 不把 games、factory、main 的页面主题混写。

## 优化优先级

1. 相关 query 已经出现，且页面匹配正确。
2. 排名 8-30 的页面。
3. 排名 30-80，但主题明显相关的页面。
4. 已有曝光但内链很弱的页面。
5. query 不相关或页面未知的记录先观察。
