README:

```md
# Supplier Communication Notes

A small public resource for overseas buyers preparing early conversations with Chinese suppliers.

This is not a replacement for professional checks. It is a practical note set for asking clearer questions before sample orders, reading supplier replies more carefully, and preparing buyer-understandable product materials.

## What this covers

- Questions to ask before a sample order
- How to compare supplier replies from a communication angle
- What factory photos and product materials can clarify
- How to keep product requirements readable for both sides

## Useful pages

- [field materials for buyer trust](https://gewuji.dev/field-materials/)
- [supplier communication support](https://gewuji.dev/for-buyers/)
- [factory materials rewritten into buyer-understandable English](https://gewuji.dev/for-factories/)

## Notes

The goal is better communication before deeper commercial decisions. Smooth replies alone are not proof. Specific photos, product details, packaging notes, sample steps, and clear limits usually matter more.
```
