# Gewuji GEO Checklist

这份检查清单用于检查存量页面是否适合被搜索引擎和 AI 回答系统读取、摘录和引用。

适用页面：

- `/for-buyers/`
- `/for-factories/`
- `/field-materials/`
- `/buyer-guides/`
- `/china-supplier-checklist/`
- `/rfq-template-for-chinese-suppliers/`

## 1. Quick Answer

- [ ] 页面首屏有 2-4 句直接回答
- [ ] 回答能脱离上下文单独成立
- [ ] 不使用夸大承诺

## 2. Clear H1 / H2

- [ ] H1 唯一
- [ ] H1 清楚表达页面主题
- [ ] H2 清晰
- [ ] H2 尽量使用问题或判断场景

## 3. Checklist / Table

- [ ] 页面包含清单、表格或步骤
- [ ] 每一项都是可执行检查点
- [ ] 表格不依赖复杂 JS 渲染

## 4. FAQ

- [ ] 有 4-6 个 FAQ
- [ ] FAQ 回答真实追问
- [ ] FAQ 避免营销话术

## 5. Boundary

页面必须说明：

- [ ] not formal factory audit
- [ ] not legal due diligence
- [ ] not quality inspection
- [ ] not supplier reliability guarantee

## 6. Schema

- [ ] Article
- [ ] FAQPage
- [ ] BreadcrumbList
- [ ] HowTo for checklist/tutorial pages
- [ ] ItemList for guide index pages

## 7. Internal Links

页面应链接到：

- [ ] `/for-buyers/`
- [ ] `/for-factories/`
- [ ] `/field-materials/`
- [ ] `/buyer-guides/`
- [ ] 相关 guide

## 8. Freshness

- [ ] 有 updated date
- [ ] 日期真实反映内容更新
- [ ] 过期平台规则或样例已更新

## 9. E-E-A-T

- [ ] 有克制的项目说明
- [ ] 表达基于工厂资料、供应商沟通和现场素材观察
- [ ] 不夸大资质
- [ ] 不把 Field Materials 写成审厂证明

## 10. No Guarantee Language

禁止使用：

- [ ] guarantee supplier safety
- [ ] safe order guarantee
- [ ] certified verification
- [ ] formal audit
- [ ] inspection proof
- [ ] supplier reliability guarantee
