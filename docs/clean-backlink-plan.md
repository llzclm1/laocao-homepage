# 干净外链建设计划

这份计划用于给格物集主站和 Factory Bridge 建设自然、相关、低风险外链。

## 优先推广页面

- `/`
- `/for-buyers/`
- `/for-factories/`
- `/field-materials/`
- `/tools/`

## 后续内容页

- `/china-supplier-checklist/`
- `/supplier-red-flags-before-sample-order/`
- `/rfq-template-for-chinese-suppliers/`
- `/sample-order-email-template/`
- `/product-materials-for-overseas-buyers/`

## 推荐干净外链来源

- LinkedIn profile
- About.me
- GitHub profile
- GitHub README
- Medium article
- Quora answer
- Reddit natural answer
- Notion public checklist
- personal homepage
- relevant sourcing/importing resource pages
- B2B service directories
- startup/tool directories only when relevant

## 推荐自然锚文本

- Gewuji
- Gewuji Factory Bridge
- Factory Bridge by Gewuji
- supplier communication support
- China supplier checklist
- practical sourcing communication guide
- field materials for buyer trust
- product materials for overseas buyers

## 避免锚文本

- best China supplier guaranteed
- safe supplier guaranteed
- factory audit service
- legal due diligence
- high DR backlinks
- SEO backlinks
- casino
- crypto
- money keywords repeated too often

## 执行顺序

1. 先补个人和项目资料页：LinkedIn、GitHub profile、About.me、personal homepage。
2. 再做内容型外链：Medium、Notion public checklist、GitHub README。
3. 最后做自然回答型外链：Quora、Reddit、相关 sourcing/importing resource pages。
4. 每次新增外链后，记录到 `data/backlinks/backlink-audit-log.csv`。

## 判断标准

干净外链不追求数量，优先满足：

- 来源页面和中国供应商、采购沟通、工厂资料、实地素材相关。
- 锚文本自然，不堆关键词。
- 不承诺保证安全供应商，不写审厂、法律尽调或质量验货服务。
- 用户点进去后能理解链接为什么存在。
