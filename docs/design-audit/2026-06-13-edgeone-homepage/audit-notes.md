# 老曹造物集首页设计审查

审查对象：https://gewuji.dev/

审查时间：2026-06-13

- `03-mobile-hero-projects.png`：移动端首屏与项目入口

## 总体判断

当前页面已经具备可信、友好、轻科技感的个人项目主页气质。品牌名、项目数量、项目卡片、FAQ 和联系入口都清楚，适合普通用户、合作方和投资人快速建立第一印象。

综合健康度：良好，可以上线使用；下一步应优先强化首屏项目证据、移动端首屏效率和关键转化入口。

## 主要优点

1. 首屏品牌识别强。
   “老曹造物集”作为 H1 足够明确，顶部导航和 CTA 也比较克制，整体不像模板站。

2. 项目区信息密度合适。
   PixRoom、素材收纳箱、工位突围和 Motorcycle Garage 都有图片、状态、分类、简介和要点，用户能快速判断每个项目是什么。

3. 视觉语言统一。
   浅色科技背景、玻璃质感导航、项目卡片和蓝绿色强调色比较一致，已经形成“高级产品感”的基础。

4. 移动端基础可用。
   当前截图未见横向溢出，文字阅读顺序正常，FAQ 在手机上可扫描。

## 主要问题

1. 首屏项目证据偏弱。
   桌面端首屏背景项目图太淡，移动端首屏几乎看不到项目截图。用户第一眼知道这是主页，但不够快地看到“这些项目长什么样”。

2. 移动端首屏效率可以更高。
   顶部导航占高偏大，统计卡占据较多纵向空间，导致“正在推进的项目”标题在首屏下方才出现。

3. 转化入口还可以更直接。
   “联系合作”存在，但首屏没有直接暴露邮箱或更明确的合作动作。合作方和投资人需要多一步跳转或滚动。

4. 交互暗示仍有提升空间。
   项目筛选按钮可见，但筛选结果反馈较弱；FAQ 使用浏览器默认三角，基础可用但不够精致。

## 建议优先级

### P1：强化首屏项目实感

- 让首屏右侧项目预览更清晰，至少保留 1-2 个可辨认项目截图。
- 移动端可以在 H1 下方增加一个横向项目缩略条，露出 PixRoom、素材收纳箱等代表图。
- 保持浅色和高级感，但不要让产品证据淡到接近装饰背景。

### P2：压缩移动端首屏高度

- 移动端导航改为更紧凑的两行或一行横滑。
- 统计卡从三段竖排改为三列小型指标，减少纵向占用。
- 目标是在 390px 宽手机首屏内同时看到标题、简介、CTA 和一部分项目入口。

### P3：增强合作转化

- 首屏 CTA 附近增加一个轻量邮箱入口，例如“邮件联系 25132283@qq.com”。
- 项目卡片的“了解合作 / 关注进展”可以统一为更明确的动作文案。
- 联系区可增加“适合合作的方向”，帮助合作方快速判断是否该联系。

### P4：做一次可访问性和交互验证

- 检查浅色背景上的小字对比度。
- 检查键盘 Tab 顺序、按钮焦点态、FAQ 展开状态。
- 检查项目筛选在移动端的可点击范围和结果反馈。
