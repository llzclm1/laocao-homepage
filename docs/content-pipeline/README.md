# Content Pipeline

This folder stores one folder per Growth OS opportunity.

## Folder Contract

Each opportunity folder should contain:

- `opportunity.md`
- `brief.md`
- `draft.md`
- `schema-plan.md`
- `distribution.md`
- `geo-monitoring.md`
- `review.md`

## Status Flow

```text
approved
-> brief_ready
-> draft_ready
-> review_ready
-> published_candidate
-> distributed
-> monitoring
-> improve_or_stop
```

## Boundary

Content pipeline drafts must support:

- communication clarity
- missing information
- buyer questions
- next steps

They must not imply:

- supplier verification guarantee
- factory audit
- quality inspection
- payment protection
- supplier reliability guarantee
