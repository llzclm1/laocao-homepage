# Social Distribution Queue

This queue stores reviewed drafts for manual distribution. It is not an automation system.

## Status Values

- `draft`
- `review`
- `published`
- `measured`

## Rules

Allowed:

- LinkedIn post draft
- Reddit discussion draft
- Quora answer draft
- Substack outline

Forbidden:

- automatic spam
- automatic comments
- fake accounts
- aggressive link dropping
- private messages without human review
