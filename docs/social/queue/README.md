# Social Distribution Queue

这里记录发布后需要人工审核和人工分发的内容。它不是自动发帖系统。

## 原则

允许：

- Reddit helpful answer draft
- Quora answer draft
- LinkedIn post draft
- Medium / Substack outline
- Spanish forum reply draft

禁止：

- 自动评论
- 自动发帖
- 群发私信
- 垃圾外链
- 伪装成用户评价
- 在不适合放链接的场景强行放链接
