# Feedback Loop

The Feedback Loop turns performance and buyer signals into content and service improvements.

## Inputs

- `data/growth-os/content-status.json`
- GSC observations
- AI-search monitoring
- distribution responses
- anonymous buyer questions
- anonymous supplier reply patterns

## 30-Day Review

Every 30 days, review:

- traffic
- ranking
- AI citation
- conversion
- external discussion
- recurring buyer questions

## Optimization Queue

Create an optimization task when:

- a page gets impressions but low CTR
- AI answers miss Gewuji's core boundary
- external replies reveal better buyer wording
- a page attracts the wrong intent
- a real buyer question repeats

## Decision Values

- update
- expand
- merge
- distribute
- monitor
- stop
