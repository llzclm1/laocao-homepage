# SEO Monitoring

SEO monitoring tracks whether a page is crawled, indexed, discovered, and worth improving.

## Timeline

| Time | Check |
|---|---|
| 48 hours | crawl and indexing only |
| 7 days | query discovery and impressions |
| 28 days | CTR and average position |
| 90 days | expand, merge, rewrite, or stop |

## Fields

- URL
- publish date
- indexed
- impressions
- clicks
- CTR
- average position
- top queries
- conversion signal
- next action

## Decision

| Signal | Action |
|---|---|
| indexed but no impressions | wait or improve internal links |
| impressions but low CTR | improve title/meta |
| wrong queries | rewrite direct answer |
| conversions or useful questions | expand page |
| no signal after 90 days | merge or stop |
