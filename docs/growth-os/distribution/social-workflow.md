# Distribution Workflow

Distribution starts only after a page exists or a draft is explicitly approved for external discussion.

## Inputs

- published URL
- `docs/content-pipeline/<id>/distribution.md`
- review status

## Outputs

- LinkedIn draft
- Reddit discussion draft
- Quora draft
- Substack draft

## Status Flow

```text
draft
-> review
-> published
-> measured
```

## Rules

Do not:

- auto-post
- auto-comment
- use fake accounts
- spam links
- accuse suppliers
- promise verification, audit, quality, payment safety, or supplier reliability

Do:

- answer the question directly
- disclose uncertainty
- keep links optional
- prefer helpful explanation over promotion
