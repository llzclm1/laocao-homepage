# Page Release Checklist

Use this before moving an approved draft into a website page.

## Required Page Elements

- Title
- Meta description
- H1
- TL;DR
- Direct Answer
- FAQ
- Schema
- Internal links
- CTA
- Boundary statement

## Internal Link Requirements

For buyer-side content, check whether these are relevant:

- `/supplier-reply-review/`
- `/supplier-reply-review/sample-report/`
- `/supplier-reply-review/examples/`
- `/field-materials/`
- `/buyer-guides/`

## CTA Order

For Supplier Reply Review related pages:

1. Supplier Reply Review
2. Sample Report
3. Examples

## Page-Ready Decision

Output `page-ready` only when:

- direct answer appears near the top
- boundary is visible near the top or CTA
- FAQPage schema matches visible FAQ
- Article schema does not overclaim
- links work locally
- no prohibited claims appear

## Prohibited At Release

- no hidden guarantee in schema
- no "verified supplier" CTA
- no fake case study
- no automatic publication without review
