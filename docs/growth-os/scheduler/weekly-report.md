# Weekly Report

## Purpose

Summarize SEO, GEO, distribution, and feedback signals.

## Steps

1. Read content status.
2. Generate GEO report shell.
3. Summarize SEO observations.
4. Summarize distribution status.
5. Create optimization candidates.
6. Feed repeated questions back into Opportunity Agent.

## Inputs

- `data/growth-os/content-status.json`
- future `data/growth-os/monitoring-results.jsonl`
- `docs/growth-os/monitoring/geo-monitoring.md`
- `docs/social/queue/`

## Outputs

- weekly GEO report
- SEO status notes
- optimization queue

## Human Checkpoint

No public claim can be made from monitoring data without manual review.
