# Growth OS Scheduler

Scheduler v1 defines local run order for autonomous mode. It does not execute external platform actions.

## Runs

- Daily Run: opportunity scan and queue update
- Weekly Report: GEO, SEO, and content performance review

## Files

- `daily-run.md`
- `weekly-report.md`

## Boundary

Scheduler can create local candidates and reports only. It cannot publish pages, send posts, submit forms, or contact people.
