# Distribution Agent

## Input

- published URL
- `docs/content-pipeline/<go-id>/distribution.md`
- `docs/social/queue/README.md`

## Process

1. Prepare LinkedIn draft.
2. Prepare Reddit discussion draft.
3. Prepare Quora draft.
4. Prepare Substack outline.
5. Set status to `draft` or `review`.

## Output

- manual social queue entry
- platform-specific drafts

## Human Checkpoint

Required before every external post, reply, comment, or message.
