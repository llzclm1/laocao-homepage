# Research Agent

## Input

- opportunity ID
- local question notes
- existing Gewuji pages and content pipeline files

## Process

1. Check whether Gewuji already has coverage.
2. Identify buyer pain, intent, and likely conversion path.
3. Record missing information.
4. Flag boundary risks.

## Output

- `docs/content-pipeline/<go-id>/opportunity.md`
- research notes inside the content package

## Human Checkpoint

Required before using research notes to create a page or public reply.
