# Monitoring Agent

## Input

- `data/growth-os/content-status.json`
- `docs/growth-os/monitoring/geo-monitoring.md`
- manual SEO/GEO observations

## Process

1. Read content status.
2. Read monitoring prompts.
3. Summarize SEO status.
4. Summarize GEO status.
5. Flag accuracy or boundary problems.

## Output

- `docs/geo-monitoring/geo-report-YYYY-MM-weekN.md`
- content status updates

## Human Checkpoint

Required before using monitoring results for public claims or website copy.
