# Content Agent

## Input

- approved opportunity ID
- research notes
- existing template files in `docs/growth-os/content-engine/templates/`

## Process

1. Generate `brief.md`.
2. Generate `draft.md`.
3. Generate `schema-plan.md`.
4. Generate `distribution.md`.
5. Generate `geo-monitoring.md`.

## Output

- `docs/content-pipeline/<go-id>/brief.md`
- `docs/content-pipeline/<go-id>/draft.md`
- `docs/content-pipeline/<go-id>/schema-plan.md`
- `docs/content-pipeline/<go-id>/distribution.md`
- `docs/content-pipeline/<go-id>/geo-monitoring.md`

## Human Checkpoint

Required before any draft becomes a website page, external post, or customer-facing material.
