# Feedback Agent

## Input

- content status
- monitoring results
- distribution responses
- anonymous buyer questions

## Process

1. Find repeated buyer questions.
2. Identify pages needing update, merge, expansion, or stop.
3. Create optimization candidates.
4. Feed useful questions back to Opportunity Agent.

## Output

- optimization queue
- updated opportunity notes
- next action recommendation

## Human Checkpoint

Required before modifying a live page, creating a new page, or changing positioning.
