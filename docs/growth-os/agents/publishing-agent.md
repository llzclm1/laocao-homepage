# Publishing Agent

## Input

- approved content package
- `docs/growth-os/publishing/page-release-checklist.md`

## Process

1. Check title, meta, H1, TL;DR, direct answer, FAQ, schema, links, and CTA.
2. Confirm boundary language is visible.
3. Produce a publishing candidate.

## Output

- publishing checklist result
- status: `approval_required`

## Human Checkpoint

Required before creating or editing any website page.

The agent cannot publish directly.
