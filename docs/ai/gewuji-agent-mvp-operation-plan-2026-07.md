# Gewuji AI Agent MVP Operation Plan

## 当前目标

验证 Agent 系统是否能持续产生：

- Buyer Question
- Buyer Guide 机会
- Supplier Reply Review 素材
- 社媒回复机会

不是追求自动化。

---

## 每日运行流程

### Step 1

Social Intelligence Agent

输入：

- Reddit
- Quora
- LinkedIn 公开讨论

输出：

daily-social-opportunity.md

字段：

- 问题
- 来源
- 采购阶段
- 相关材料
- 建议回复

---

### Step 2

人工筛选

分类：

- Reply
- Ignore
- Convert to Buyer Guide

---

### Step 3

SEO GEO Agent

判断：

- 是否已有页面覆盖
- 是否进入 Buyer Question Knowledge Base

---

### Step 4

Content Agent

生成：

- 社媒回复草稿
- Buyer Guide 优化建议

---

### Step 5

Supplier Review Agent

沉淀：

- 判断规则
- 模板
- 案例

---

## 每周复盘

Project Brain 检查：

1. 哪些问题重复出现？
2. 哪些问题适合转页面？
3. 哪些问题带来真实交流？
4. 哪些 Agent 输出没有价值？

---

## MVP 指标

30 天：

收集：

50 个 Buyer Questions

完成：

20 个高质量回复草稿

形成：

5 个 Supplier Review 案例

优化：

3-5 个 Buyer Guide 页面

---

不要：

- 自动发布
- 自动评论
- 自动外联
