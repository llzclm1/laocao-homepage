# Gewuji AI Agent Data Flow

## 核心循环

Social Intelligence Agent

↓

发现海外买家真实问题

↓

Buyer Question Knowledge Base

↓

SEO GEO Agent

↓

判断：

- 是否已有页面覆盖
- 是否需要优化
- 是否进入内容规划

↓

Content Agent

↓

生成：

- Buyer Guide
- LinkedIn 内容
- Reddit 回答
- Quora 回答

↓

Supplier Review Agent

↓

沉淀：

- 判断规则
- Review 模板
- 案例

↓

Project Brain

↓

每周复盘：

- 哪些问题出现频率高
- 哪些内容值得投入
- 哪些方向暂停

---

## Agent 边界

Social Intelligence Agent：

负责：

- 发现
- 分类
- 草稿

不负责：

- 发布
- 销售
- 自动互动

SEO GEO Agent：

负责：

- 内容机会判断
- GEO 结构

不负责：

- 社媒执行

Content Agent：

负责：

- 内容转换

不负责：

- 决定战略

Supplier Review Agent：

负责：

- 判断模板

不负责：

- 自动判断供应商可靠性

---

## 当前 MVP 原则

先跑：

人工审核闭环。

不要：

自动发布。

不要：

自动评论。

不要：

自动外联。
