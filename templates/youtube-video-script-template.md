# YouTube Video Script Template

Use this template to turn a buyer guide, supplier reply review example, or field material note into a short YouTube asset.

## Video Title

Specific buyer question.

## Format

Choose:

- Short, 30-45 seconds
- Explainer, 3-5 minutes

## Source Page

Website URL used as source.

## Hook

One sentence that names the buyer risk.

Example:

```text
Before paying a Chinese supplier, don't just ask if they can make it.
```

## Short Answer

2-3 sentences.

## Main Points

3-5 points.

## Generic Example

Optional.

Use only generic examples, not real supplier data.

Example:

```text
Supplier says:
"Yes, we can make it. Sample fee is $120. Delivery 7 days."
```

This still does not confirm:

- material
- packaging
- shipping
- payment account match
- bulk production terms

## Boundary Note

Required.

Example:

```text
This does not prove whether a supplier is reliable. It only helps you find unclear points before payment.
```

## CTA

Soft CTA only.

Examples:

- See the sample supplier reply review report on Gewuji.
- Compare your supplier reply against a checklist before paying.

## Description Links

Optional:

- Supplier Reply Review
- Sample Report
- Relevant Buyer Guide

## Privacy Check

Confirm:

- no customer names
- no factory names
- no logos
- no drawings
- no order details
- no faces
- no sensitive labels
- no fake footage
- no guarantee language
