Turn a product page into a comparison you can check.

Product Spec Grabber reads the product page you are already viewing, organizes visible specifications, and keeps the source evidence beside each value.

Local-first v0.2.0. It reports information found on the page; it does not certify a product, verify a manufacturer, or promise that a page is complete.

One click from page to structured product.

The extension is designed for the moment when you are comparing real product pages: tools, equipment, appliances, coffee machines, or other products with specifications spread across different layouts.

1. Read the page

Click the extension on a normal product page. The current page is read on demand with temporary access.

2. Keep the evidence

Values can retain the source URL, original wording, and a page locator so you can return to the claim.

3. Compare what differs

Add products to one local project and review missing fields, conflicts, and unsupported mappings before deciding.

From scattered claims to a visible decision surface.

Product pages rarely use the same field names or page structure. Product Spec Grabber starts with common page signals and maps them to a shared product schema without hiding uncertainty.

Built for page evidence, not confident-sounding guesses.

JSON-LD, Schema.org data, specification tables, definition lists, headings, and labeled text sections are useful signals. When a value cannot be mapped confidently, the result keeps that limitation visible.

Missing

An expected field was not found in the current page content.

Conflict

Different visible values appear for the same normalized field and need review.

Unsupported

The page contains a claim that the current schema cannot map with enough confidence.

Save the research trail locally.

Add a product to a Project, add the next product to the same comparison, then export JSON or CSV when you need to share or continue the work elsewhere.

  • ProjectKeep products that belong to one buying or research question together.
  • ComparisonSee aligned fields and the places where values are absent or inconsistent.
  • EvidenceReturn to the original URL, wording, and page location instead of relying on memory.
  • ExportDownload the current local comparison as JSON or CSV.
