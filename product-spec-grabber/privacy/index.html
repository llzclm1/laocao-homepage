Product Spec Grabber / Privacy

Your product research stays on your device in v0.2.0.

Product Spec Grabber reads the page you are viewing only after you click the extension. This policy explains what it reads, what it saves locally, and what it does not send anywhere.

Effective date: September 17, 2026 · Version: v0.2.0

Short version
  • No account or login
  • No page HTML upload
  • No remote API sync
  • No sale of browsing data

What the extension reads

When you request extraction, the extension reads information available in the current page, such as the page URL, title, product name, brand, model, visible specification text, JSON-LD or Schema.org data, specification tables, definition lists, headings, and labeled specification sections.

  • WhenOnly after you click the Product Spec Grabber extension action or ask the Side Panel to refresh the current page.
  • WhereOn the active normal `http(s)` page that Chrome permits the extension to read.
  • EvidenceThe extension can preserve the source URL, page locator, and a short original text excerpt beside an extracted value.
  • Not read automaticallyThere is no background browsing, continuous page monitoring, or automatic access to all websites in v0.2.0.

What is stored locally

Product Spec Grabber uses Chrome extension local storage for the local comparison workflow. This can include normalized product fields, observations, Missing / Conflict / Unsupported findings, Projects, comparison state, source URLs, DOM locators, and evidence excerpts that you choose to retain.

Projects and products

Products you add to a local project and the comparison fields generated from the current page.

Evidence

Source URL, page location, and short original excerpts used to check a field later.

Exports

JSON and CSV files are created only when you choose to export the current local comparison.

What v0.2.0 does not do

This release is deliberately local-first. It does not need a user account or a server to extract and compare a page.

  • No uploadPage HTML and extracted product data are not uploaded to GEWUJI or a third-party API in v0.2.0.
  • No saleGEWUJI does not sell browsing data or use Product Spec Grabber to build an advertising profile.
  • No verification claimThe extension reports visible page information; it does not verify a manufacturer, certify a product, or guarantee a specification.
  • No remote codeExecutable extension code is packaged in the Chrome Web Store ZIP. The extension does not load remote executable code.

Permissions

Product Spec Grabber requests only the permissions needed for its current local workflow.

  • activeTabTemporary access to the current page after your click.
  • scriptingOn-demand injection of the page extractor after that user gesture.
  • sidePanelDisplay the extraction and comparison interface in Chrome's Side Panel.
  • storageSave local Projects, products, findings, comparison state, and evidence.

How to delete local data

Delete Projects from the extension interface when that control is available. You can also remove Product Spec Grabber from Chrome and clear the extension's stored data through Chrome's extension settings. Exported JSON or CSV files are separate files on your device and must be deleted separately.

Questions or a deletion request

Contact GEWUJI support at llzclm@gmail.com.

Please do not send page HTML, customer names, payment details, or confidential drawings unless they are necessary for the support question.
