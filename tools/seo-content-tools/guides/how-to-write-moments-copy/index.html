简明回答

朋友圈文案怎么写

  1. 先说清楚你要宣传什么，不要一开始就堆形容词。
  2. 再说明适合谁、有什么亮点、怎么参与。
  3. 最后用轻一点的行动引导，比如“有需要可以私信”或“到店出示即可”。

示例

可以这样写

今天想推荐一个小活动：夏日冰拿铁第二杯半价。适合下午和朋友一起过来坐坐，活动时间是工作日下午 2 点到 5 点，到店出示这条即可参与。
