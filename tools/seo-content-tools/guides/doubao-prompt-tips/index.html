豆包生图提示词怎么写

  1. 提示词要写清主体、场景、风格、光线、构图和用途。
  2. 如果是商品宣传图，要补充商品细节和使用场景。
  3. 不要只写“好看高级”，要说清楚画面应该出现什么。
