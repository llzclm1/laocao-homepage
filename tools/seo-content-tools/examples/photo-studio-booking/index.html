同一个主题的多平台写法

朋友圈文案

本月写真档期还剩几个空位，适合想记录近期状态、换头像或准备生日照的朋友。风格偏自然，不会过度摆拍，喜欢的话可以提前沟通时间。

小红书文案

标题：想拍一组自然一点的写真，可以先看这个风格 正文：这组更适合不喜欢夸张摆拍的人，重点是记录状态和情绪。拍摄前会先沟通服装、场景和用途。

短视频脚本

开头：很多人想拍写真，但怕尴尬。 中段：展示自然风格客片和拍摄过程。 结尾：本月还有少量档期，想拍可以提前约。

社群通知

本月写真档期还剩少量空位，需要拍头像、生日照或纪念照的朋友可以提前预约。
